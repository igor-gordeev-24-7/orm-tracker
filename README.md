Для чего нужен Psycopg? - драйвер передающий команды postgressql и возвращающий ответ

Для чего нужен Engine? - через него происходит подключение к базе и передеча запросов

Является ли Engine одним постоянно открытым соединением? - это не одно соединние а фабрика соединений

Для чего нужна Session? - это объект через котрый программа загружает ORM объекты, следит за их изменениями и сохраняет эти изменения в одной транзакции

Чем session.add() отличается от session.commit()? - добавляет объект в рабочую область сесии, коммит, сохраняет измеенния в БД, подтверждает транзацию
